# Changelog

Notable changes per release. Versions follow [SemVer](https://semver.org/).

## v0.1.0 — 2026-11-11

- First release. Right-click a session in the left session list to apply one of
  eight low-saturation gradient washes; the last blank row removes the mark. The
  wash is a single `background-image`, so text, layout, and the harness's
  hover/selected feedback are unchanged. Includes light/dark themes,
  `localStorage` persistence, and cross-tab sync.
- 中文：首个版本。右键左侧会话套用八档低饱和渐变底纹，最后一条空白条清除；
  只改一层 `background-image`，不动文字、布局和宿主反馈。支持亮/暗主题、
  `localStorage` 持久化与同源标签页同步。
